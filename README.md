# EduMetrics – Student Academic Performance Management System

A browser-based academic project built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. No installation or server is required for the included local-demo features.

## Included modules
- Overview dashboard and KPIs
- Student records: add, edit, delete, search and grade filter
- Academic analytics and subject averages
- Attendance marking (browser-local demo)
- Semester record labels (additional marks must be supplied)
- Individual report card and print/PDF
- Rule-based academic recommendations
- CSV import/export
- Light/dark mode
- Browser-local saving and reset to original data

## Important limitations
- All 25 starter student records are fictional sample records from the supplied workbook.
- Attendance and additional semester data are not present in the original workbook; those sections are demonstration modules and require real or clearly labelled sample entries.
- Data is stored in the current browser using localStorage. It is not a cloud database and is not shared between devices.
- This version has no real authentication, role-based permissions or server-side database.
- Google Fonts requires internet access; the system fonts are fallback options.
