# EduMetrics – Student Performance Analysis Dashboard

A web-based dashboard designed to organize student academic records, analyze performance, and present useful academic insights through a simple and interactive interface.

## 🌐 Live Website

[Open EduMetrics Dashboard](https://monikakommineni-ui.github.io/Student-Performance-Analysis-Dashboard/)

## 📌 Project Overview

EduMetrics is a Student Performance Analysis Dashboard developed as part of the Digital Literacy (SEC102) project at SRM University-AP.

The project aims to make student academic information easier to manage and understand. It provides a centralized interface to view student records, analyze subject-wise performance, monitor attendance, and generate student report cards.

The dashboard uses fictional sample student data for demonstration purposes.

## 🎯 Objectives

- Organize student academic records in one place.
- Analyze student performance across different subjects.
- Display academic statistics and performance trends.
- Monitor student attendance.
- Generate individual student report cards.
- Provide recommendations based on academic performance.

## ✨ Key Features

- **Overview Dashboard:** Displays important academic statistics.
- **Student Management:** Add, edit, delete, search, and filter student records.
- **Academic Analytics:** View subject averages, student rankings, and pass percentages.
- **Attendance Management:** Record and manage attendance.
- **Report Card Generator:** Generate printable student report cards.
- **Academic Recommendations:** Display suggestions based on student performance.
- **Data Centre:** Import and export student data using CSV files.
- **Theme Settings:** Switch between light and dark themes.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Interactive features and data handling
- Browser Local Storage – Saving demonstration data
- GitHub – Source code management
- GitHub Pages – Website hosting

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the dashboard and its features.

Alternatively, access the live website using the link provided above.

## ⚠️ Project Limitations

- The project uses sample data for demonstration.
- Data is stored locally in the browser.
- It does not currently use a cloud database or backend server.
- Data is not automatically shared across different devices.
